# Generate Creative Metadata

Generate exactly one title and one description from the supplied transcript.

## Workflow

1. Identify the central topic and the most useful specific point in the transcript.
2. Write one clear title with at most 100 characters.
3. Write a natural description in two to four paragraphs covering the topic, main points and value.
4. Return only `# Título` and `# Descrição` sections in Brazilian Portuguese.

## Rules

- Use only information supported by the transcript.
- Avoid misleading clickbait.
- Do not invent products, prices, results, proof, links, hashtags or calls to action.
- Do not add campaign strategy, audiences, targeting, creative variants or A/B tests.
